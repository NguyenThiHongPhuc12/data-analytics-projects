# Data Analytics Portfolio
## About

A collection of data analytics projects covering EDA, machine learning, 
and business intelligence dashboards. Built with Python and Power BI.

Repository này chứa các project phân tích dữ liệu và dashboard được thực hiện trong quá trình học và thực hành Data Analytics.

Các project tập trung vào:
- Data Analysis
- Data Visualization
- Machine Learning
- Marketing Analytics
- Business Insights

## Công cụ sử dụng
- Python
- Pandas
- Scikit-learn
- Power BI
- Data Visualization

# Danh sách Project

## 1. TikTok Creator Engagement Dashboard
Phân tích mức độ tương tác của các TikTok Creator dựa trên các chỉ số như:
- Views
- Likes
- Comments
- Shares
- Followers
- Engagement Rate
Mục tiêu là tìm hiểu mối quan hệ giữa quy mô người theo dõi và mức độ tương tác của creator.
Công cụ sử dụng:
- Power BI
- Data Visualization
Project folder: project-1-tiktok-dashboard

## 2. Bank Customer Churn Analysis
Phân tích dữ liệu khách hàng ngân hàng để dự đoán khả năng khách hàng rời bỏ dịch vụ.
Các bước thực hiện:
- Exploratory Data Analysis (EDA)
- Data preprocessing
- Feature analysis
- Machine learning modeling
Các mô hình được sử dụng:
- Logistic Regression
- Random Forest
- Decision Tree
- XGBoost
Công cụ sử dụng:
- Python
- Pandas
- Scikit-learn
- Machine Learning
Project folder: project-2-bank-churn-analysis

## 3. Digital Advertising Performance Analysis
Phân tích hiệu suất quảng cáo digital trên nhiều nền tảng:
- Google Ads
- Meta Ads
- TikTok Ads
Phân tích các chỉ số marketing quan trọng:
- Ad Spend
- Revenue
- ROAS
- CTR (Click Through Rate)
- CPC (Cost Per Click)
- Conversion Rate
Dashboard giúp đánh giá:
- hiệu quả chiến dịch quảng cáo
- hiệu suất theo nền tảng
- hiệu suất theo campaign
- hiệu quả theo thị trường
- ROI theo ngành
Công cụ sử dụng:
- Python
- Power BI
- Data Visualization
Project folder: project-3-digital-advertising-analysis

# Mục tiêu của Portfolio

Các project trong repository này được thực hiện nhằm:
- rèn luyện kỹ năng phân tích dữ liệu
- xây dựng dashboard trực quan
- tìm ra insight từ dữ liệu
- hỗ trợ ra quyết định dựa trên dữ liệu
